# 🧠 What is TradeLab?

TradeLab is a full-stack web application designed to demonstrate how a simplified algorithmic trading system works.

Instead of only displaying a market chart, TradeLab provides a complete simulation workflow:

```text
Generate Market Data
        ↓
Calculate Technical Indicators
        ↓
Create Trading Strategy
        ↓
Define BUY / SELL Conditions
        ↓
Run Backtest
        ↓
Generate Trading Signals
        ↓
Execute Simulated Trades
        ↓
Update Portfolio
        ↓
Calculate Performance
        ↓
Analyse Results
